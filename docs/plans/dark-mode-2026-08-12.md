# Sötét mód — ReceiptLens specifikáció

**Dátum**: 2026-08-12
**Státusz**: Tervezés kész → kanban
**Scope**: frontend only (nincs backend/API változás)

---

## 1. Probléma & Scope

A ReceiptLens frontend **már rendelkezik dark mode alapokkal** (ThemeToggle komponens, `darkMode: "class"` Tailwind config, `.dark` class a `<html>`-en, `dark:` variánsok a shell-ön és az auth oldalakon). A tesztelés során **4 komponens hiányos** — fix színeket használ dark variáns nélkül:

| Fájl | Probléma |
|---|---|
| `app/(app)/inbox/page.tsx` | `text-slate-500`, `bg-slate-100` badge, `border-red-200` error — dark nélkül |
| `app/(app)/automations/[id]/page.tsx` | `border-amber-300` conflict, `text-slate-500` — dark nélkül |
| `app/(app)/exports/runs/[id]/page.tsx` | `text-slate-500` dt-k, `card` nélküli WorkflowState — dark nélkül |
| `components/WorkflowState.tsx` | `bg-white`/`bg-red-50`/`text-red-900` — dark nélkül |

**Ezen kívül hiányzó, a teljes élményhez kell**:
- **FOUC (flash of unstyled content)**: a ThemeToggle csak mount után állítja a `dark` class-t → az első betöltésnél világos villanás dark preferencia esetén. Fix: `next-themes` vagy inline script a `<head>`-ben.
- **`themeColor`** a `layout.tsx`-ben fix `#1d5ef1` — dark-ban más érték kell (pl. `#0f172a`).
- **`appleWebApp.statusBarStyle`**: `"default"` → `"black-translucent"` dark-hoz.

## 2. Tervezett UI — színek

A meglévő `brand` palette + Tailwind `slate` skála alapján, konzisztens a jelenlegi dark színrendszerrel:

| Token | Light | Dark |
|---|---|---|
| Háttér (app) | `slate-50` | `slate-950` |
| Háttér (card) | `white` | `slate-900` |
| Border | `slate-200` | `slate-800` |
| Elsődleges szöveg | `slate-900` | `slate-100` |
| Másodlagos szöveg | `slate-500/600` | `slate-400` |
| Akcent (brand) | `brand-600` | `brand-400` |
| Aktív nav | `brand-50` bg / `brand-700` text | `brand-950` bg / `brand-300` text |
| Error | `red-50` bg / `red-900` text | `red-950` bg / `red-300` text |

| Warning (conflict) | `amber-300` border | `amber-500/30` border |

## 3. Módosítandó fájlok

### 3.1. `components/WorkflowState.tsx` (központi — mindenhol látszik)
```tsx
const tone = kind === "error"
  ? "border-red-200 bg-red-50 text-red-900 dark:border-red-900 dark:bg-red-950/60 dark:text-red-200"
  : kind === "success"
  ? "border-emerald-200 bg-emerald-50 text-emerald-900 dark:border-emerald-900 dark:bg-emerald-950/60 dark:text-emerald-200"
  : "border-slate-200 bg-white text-slate-800 dark:border-slate-800 dark:bg-slate-900 dark:text-slate-200";
```

### 3.2. `app/(app)/inbox/page.tsx`
- `text-slate-500` → `dark:text-slate-400` (2×)
- `bg-slate-100` badge → `dark:bg-slate-800 dark:text-slate-300`
- `border-red-200` error card → `dark:border-red-900`
- `text-red-800` → `dark:text-red-300`
- `text-red-700` attachment error → `dark:text-red-400`
- `rounded-lg border` (attachment) → `dark:border-slate-700`

### 3.3. `app/(app)/automations/[id]/page.tsx`
- `border-amber-300` → `dark:border-amber-500/40`
- `text-slate-500` → `dark:text-slate-400`

### 3.4. `app/(app)/exports/runs/[id]/page.tsx`
- `text-slate-500` dt-k → `dark:text-slate-400`
- (WorkflowState már fixelve 3.1-ben)

### 3.5. `app/layout.tsx` — FOUC fix + themeColor
```tsx
// Inline script a <head>-ben (mielőtt a React mountol):
<script dangerouslySetInnerHTML={{__html: `
  (function(){
    var t = localStorage.getItem("receiptlens.theme");
    var dark = t ? t === "dark" : matchMedia("(prefers-color-scheme: dark)").matches;
    document.documentElement.classList.toggle("dark", dark);
  })();
`}} />
// viewport.themeColor — dinamikus? Statikus dark-kompatibilis: "#0f172a"
```
A `ThemeToggle` a localStorage-t írja, a script pedig olvassa — **konzisztens kulcs** (`receiptlens.theme`).

## 5. Teszt terv
1. **Unit (pre-tester)**: FOUC script jelen van; a 4 komponens tartalmazza a `dark:` tokeneket (snapshot/statikus).
2. **E2E (tester, browser-helper)**:
   - localStorage `receiptlens.theme=dark` → a `<html>` `.dark` class-t kap
   - FOUC: a betöltés után **azonnal** `.dark` van (nincs villanás)
   - Vizuális: inbox, automations/[id], exports/runs/[id] dark-ban kontrasztos (browser_vision)
   - Toggle: kattintás után a class vált, localStorage frissül
   - Regresszió: light mód változatlan
3. **Vizuális kontroll (browser_vision)** a kritikus oldalakon.
